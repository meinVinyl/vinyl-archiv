VINYL-ARCHIV – persönliche iPhone-Web-App

ENTHALTEN
- Platten mit Interpret, Titel, Jahr, Format, Label, Pressung und Katalognummer erfassen
- Coverfoto hinzufügen
- Suche und A–Z-Sortierung
- Hinweis auf mögliche Dubletten
- JSON-Sicherung exportieren und importieren
- Offline-Grundfunktion nach erstem Laden

WICHTIG
Diese Dateien sind noch keine im App Store veröffentlichte iPhone-App und noch nicht online installiert.
Damit „Zum Home-Bildschirm“ funktioniert, müssen die Dateien unter einer HTTPS-Adresse veröffentlicht werden.
Kostenlose Hosting-Möglichkeiten gibt es z. B. mit GitHub Pages, aber das Einrichten benötigt einige Schritte.

DATENSCHUTZ
Die Sammlung wird lokal im Browser gespeichert. Exportiere regelmäßig eine JSON-Sicherung.
Browserdaten-Löschung kann lokale Daten entfernen. Diese Version ruft keine externen Albumdaten ab und erkennt Cover nicht automatisch.

INSTALLATION NACH DEM VERÖFFENTLICHEN
1. Öffne die HTTPS-Adresse in Safari auf dem iPhone.
2. Tippe auf Teilen.
3. Wähle „Zum Home-Bildschirm“.
4. Öffne die App über das neue Symbol.

DATEIEN
index.html = Oberfläche und Funktionen
manifest.json = Web-App-Metadaten
sw.js = Offline-Cache
